# Install Inworld for the user's coding agent

Read [INSTALL.md](INSTALL.md) and choose the route for the actual host. The public release source is https://github.com/inworld-ai/plugin. Use its documented Git marketplace routes or the user's selected checkout; do not assume official marketplace approval.

1. Check Node.js is version 20 or newer. Use the existing host; do not install or authenticate another coding agent as a substitute.
2. Claude Code and Codex can register the public Git marketplace through the documented commands, which supports future refreshes. A local checkout remains an explicit alternative. For other hosts, generate only the selected package with `inworld/scripts/package-agents.mjs`, then follow its README. Output directories must be new and their parents must exist. Pointing every harness at the repository root is unsupported.
3. Configure the explicit Inworld credential through the host's approved secret flow. Give the user the [API-key page](https://platform.inworld.ai/api-keys?utm_source=other-agent&utm_medium=agent-plugin&utm_campaign=inworld-plugin&utm_content=readme) or [signup page](https://platform.inworld.ai/signup?utm_source=other-agent&utm_medium=agent-plugin&utm_campaign=inworld-plugin&utm_content=readme) when needed. Never ask for keys in chat, inspect credential stores or shell profiles, export stored CLI keys, or write keys to project files. This release uses API keys, not native MCP OAuth.
4. Change configuration only in the requested project. Preserve unrelated servers and provider choices. Existing destinations and JSONC/YAML files may require manual review; do not delete them to make installation pass. Hermes requires native installation. Generic Agent Skills and Pi packages do not provide authenticated native MCP.
5. Verify actual loaded components. Native MCP packages expose one Inworld connection and 28 tools; skills-only support does not imply tool access. Inspect registered schemas. An offline `check_speech_text` call can verify tool execution without paid requests, but does not prove authentication.
6. Report the host, installation path, credential status without values, checks performed and remaining limitations. Installation does not authorize generation, uploads, voice training, router writes, paid benchmarks, provider switching or marketplace publication.

After installation, offer a relevant first task: find a voice for the app, inspect its transcription integration, or plan a representative inference benchmark. Existing user authorization still applies; do not ask again for an already covered action.
